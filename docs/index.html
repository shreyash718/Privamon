Core Features

Privacy Without Compromise

Every layer of Privamon is designed to keep your personal data safe while giving you the full power of AI assistance.

🛡️

On-Device PII Detection

Names, emails, phone numbers, Aadhaar cards, and 20+ PII types are detected and redacted entirely on your device — nothing leaves your browser unprotected.

🤖

AI-Powered Browser Agent

Tell Privamon what you want to do in plain English. It captures, sanitizes, and consults AI to click, type, scroll, and navigate on your behalf — autonomously.

👤

Face Detection & Blur

Real-time face detection using ONNX Runtime WebGPU/WASM with automatic blur — faces are never sent to any server.

🔍

OCR + NER Fusion

Tesseract OCR combined with Transformers.js NER pipeline detects PII even inside images, screenshots, and scanned documents.

⚡

WebGPU Accelerated

NER inference runs on WebGPU when available for blazing-fast pipeline execution. Automatically falls back to WASM SIMD on unsupported hardware.

🔒

Zero Data Retention

No telemetry, no analytics, no cloud storage. The unredacted screenshot exists only in ephemeral memory and is immediately dereferenced after processing.

Getting Started

Install in 3 Steps

No Chrome Web Store needed — load directly from the ZIP file.

1

Download the Extension

Click the download button above to get the privamon-extension.zip file.

2

Unzip & Enable Developer Mode

Extract the ZIP, then open Chrome and navigate to:

chrome://extensions

Toggle "Developer mode" ON (top-right corner).

3

Load Unpacked Extension

Click "Load unpacked" and select the extracted folder. Privamon will appear in your toolbar — ready to go!
