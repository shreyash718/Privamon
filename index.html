Getting Started

Install in under two minutes

Privamon isn't on the Chrome Web Store yet — it's loaded as an unpacked developer extension. Follow these four steps to get running.

Step 1

Download the extension

Click the Download Extension button above (or download directly via this direct link) and save the privamon-extension.zip file to your computer. The package is pre-bundled with all offline AI models & OCR engines.

You need Google Chrome, Brave, or Microsoft Edge (v116+). Firefox is not supported yet.
Step 2

Extract the zip file

Right-click the downloaded .zip file and select "Extract All" (Windows) or double-click to unarchive (macOS/Linux). You'll get a folder named privamon-extension containing the extension files.

Remember where you extract it — you'll need to point Chrome to this folder. Don't delete it after loading.
Step 3

Load as unpacked extension

3a Open Chrome and navigate to chrome://extensions
3b Toggle "Developer mode" ON (top-right corner)
3c Click "Load unpacked" (top-left)
3d Select the extracted privamon-extension folder
For Brave, go to brave://extensions. For Edge, use edge://extensions. Same steps apply.
Step 4

First run — AI model warm-up

On the very first use, Privamon downloads and caches the AI models it needs for redaction. This is a one-time process — subsequent runs are instant.

Model Size Download Time
Tesseract.js OCR (English + Hindi) ~12 MB 15–30 s
UltraFace ONNX (Face Detection) ~1.2 MB 2–5 s
BERT NER (Named Entities) ~16 MB 20–40 s
Total first-run wait ~30 MB 30–90 s
Models are cached in browser storage after the first download. They persist across restarts — no re-downloading needed unless you clear site data.
Architecture

Nine stages of on-device redaction

Every frame passes through nine sequential stages — all running locally inside your browser — before any data reaches an AI model.

Phase 1

Capture & Isolate

Secure the raw frame before processing begins

01

Viewport Capture

chrome.tabs API

High-resolution PNG capture of the active viewport. Background tabs are never accessed.

Takes an instant snapshot of only what you see on screen — never hidden tabs.
02

Offscreen Sandbox

chrome.offscreen Document

Relays pixel buffers to an isolated offscreen document with full Canvas 2D and Web Worker capabilities.

An invisible sandbox where intensive scanning happens without slowing your browser.
Phase 2

Detect & Classify

Multi-modal AI finds every sensitive element

03

Parallel OCR & Face Detection

Tesseract.js + UltraFace ONNX

Multi-threaded Tesseract.js (English + Hindi) runs alongside UltraFace RFB-320 on WASM SIMD.

AI vision finds faces while OCR reads text in images, bills, and documents.
04

PII Regex & Checksum Validation

Luhn + Verhoeff Checksums

Inspects DOM text, inputs, and OCR outputs against strict checksums for Aadhaar, PAN, credit cards, and passports.

Mathematically validates numbers so real IDs are caught while normal numbers pass.
05

In-Browser NER

Transformers.js BERT

Quantized BERT Named Entity Recognition runs in-browser for contextual names, organizations, and locations.

Understands grammar to catch personal names even without explicit labels.
Phase 3

Redact & Verify

Irreversible masking with pixel-level proof

06

Spatial Fusion

IoU Clustering

Maps DOM nodes, OCR spans, and face coordinates onto a unified coordinate plane with boundary merging.

Fuses all detections so redaction borders align without exposed edges.
07

Canvas Redaction

Opaque Fill #000

Renders opaque black rectangles onto a dedicated canvas. No reversible blurs or semi-transparent masks.

Solid black ink — unlike blur, it can never be reversed.
08

Opacity Audit

Pixel Inspection Loop

Re-reads raw RGBA bytes under every masked region. Dirty pixels trigger box expansion and re-masking.

Guarantees 100% true black pixels before anything leaves your machine.
09

DOM Sanitization & Handoff

Token Replacement

Replaces sensitive tokens in the DOM tree with anonymized surrogates. The clean image goes to the AI model.

The cloud only gets the blacked-out screenshot — your secrets never leave.

Current Engineering Limitations

Transparency first · Honest hackathon assessment

Privamon is an active proof-of-concept. Below are constraints judges and testers should know:

  • 1
    Chromium MV3 Offscreen API Dependency Restricted to Chrome, Brave, and Edge (v116+). Firefox currently lacks Manifest V3 chrome.offscreen document support required for isolated background Canvas 2D and WebWorker ML inference.
  • 2
    WebGPU vs. WASM Hardware Fallback Latency WebGPU-enabled machines deliver sub-second inference (<1.5 s), but devices falling back to CPU WASM SIMD take 3.5–5.5 s per turn, alongside initial cold-start WebGPU JSEP shader compilation.
  • 3
    Multilingual Indic Script & Low-Contrast OCR While English text detection achieves >96% recall, browser-native Tesseract.js exhibits reduced accuracy on complex Devanagari ligatures, regional typography, and low-contrast physical ID photos (PAN/Aadhaar).
  • 4
    Dynamic SPA Virtual DOM & Coordinate Drift High-velocity client re-renders (React/Vue DOM updates mid-turn), CSS transforms, and fractional OS display scaling can cause spatial bounding box drift between rasterized viewport captures and live DOM nodes.
